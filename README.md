# Maki Goto — Portfolio

EC・Web制作の応募用ポートフォリオです。実務の担当範囲、制作の進め方、制作物を紹介します。

## 構成

- `index.html`：プロフィール・代表作・制作の流れ・スキル
- `works/renewal.html`：ECサイト改修。コーディングを中心とした担当範囲
- `works/lp.html`：チーズケーキ特集。各商品の特徴の整理
- `works/product.html` / `works/banner.html`：商品画像・バナー
- `gallery.html` / `js/archive.js`：過去の制作物一覧
- `css/portfolio.css` / `js/portfolio.js`：共有の表示・ナビゲーション・画像閲覧
- `cheesecake/` / `wd_2024/` / `wd_2025/` / `noel_2023/`：過去の実制作ページ

## 閲覧

ビルド不要の静的HTMLです。`index.html` をブラウザで開くか、リポジトリのルートを静的サーバーで配信します。

## 技術と担当範囲

ポートフォリオ本体はHTML/CSS/JavaScript。Google Fontsを読み込みます。画像ビューアは標準のdialog要素を利用し、キーボード操作と呼び出し元へのフォーカス復帰に対応しています。共有スタイルはCSSに集約しています。

実務作品の担当範囲は各詳細ページに記載しています。過去の特集ページは当時のライブラリや外部リソースを含みます。各ページの実装全体や掲載素材すべての自作を示すものではありません。商品の価格・キャンペーン情報は制作当時のものです。

Figma / Adobe XDの実務経験、SEO施策や売上改善の数値実績は掲載していません。検索非掲載用のnoindex設定はアクセス制限ではありません。

## 掲載物

制作物の画像・文章・商標の権利は各権利者に帰属します。応募時の実績紹介を目的とした掲載で、第三者向けの再利用素材集ではありません。
