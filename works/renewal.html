洋菓子ECサイト リニューアル

既存の洋菓子ECサイトのトップページをリニューアル。情報の見せ方とスマートフォンでの閲覧、更新作業を考えて制作しました。

担当範囲
情報設計、ワイヤーフレーム、ビジュアル制作、コーディング
使用ツール
Photoshop / Visual Studio Code / ショップサーブ

制作について

トップのビジュアルを大きくし、人気商品や季節の情報が見つけやすい構成に整理しました。スマートフォン向けのバナーと読みやすい文字サイズにも配慮し、ショップサーブで更新しやすい設計にしました。
