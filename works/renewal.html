CASE 01 / INFORMATION / CODING

洋菓子ECサイトのリニューアル

コーディングを中心に、情報整理とワイヤーフレーム作成からショップサーブのテスト環境への組み込みまで担当しました。

制作種別
実務 / ECサイト改修
主な担当
コーディング、ワイヤーフレーム作成、テスト環境への組み込み
画像制作
アイコン・バナーなど一部
使用環境
HTML / CSS / Visual Studio Code / ショップサーブ

上長と相談しながら情報を整理し、
ワイヤーフレームからテスト環境への組み込みまで。

依頼と制作体制

EC店長から、洋菓子ECサイトのリニューアルを依頼。クリエイティブチームのマネージャーと相談しながらワイヤーフレームを作成し、必要な要素を精査して制作を進めました。

私の担当範囲

サイト設計とコーディングを担当。静的HTMLを作成した後、ショップサーブのテスト環境へ組み込み。実装に必要なアイコンやバナーなど、一部の画像制作も担当。

担当の区分

依頼：EC店長
相談・確認：クリエイティブチームのマネージャー
私の担当：ワイヤーフレーム作成、静的HTML制作、テスト環境への組み込み、一部画像制作

制作で意識したこと

  1. 必要な情報を整理してから実装する

    いきなり画面を作るのではなく、上長と相談し、ワイヤーフレームで必要な要素を確認しながら進めました。

  2. タグの意味とシンプルなコード

    Web標準を意識し、内容に合ったHTMLタグの使い方と、できるだけシンプルな構造を心がけました。

  3. スマートフォンでの画像の見え方

    PCの画面を縮小するだけでなく、スマートフォンでメイン画像をどう見せるかを工夫しました。

制作の流れ

依頼・相談 → ワイヤーフレームと要素の精査 → 静的HTML制作 → ショップサーブのテスト環境へ組み込み
